# مساعد تأشيرات المافيفا (Visa Auto-Auth) ⚡

تطبيق أندرويد خفيف مخصص لتأكيد رموز التحقق MFA لتطبيق المافيفا وحجز المواعيد آلياً وفورياً، بديل احترافي متكامل لـ MacroDroid.

---

## 🚀 طريقة البناء السحابية السريعة (GitHub Actions):

1. أنشئ مستودعاً جديداً على حسابك في GitHub (مثلاً: `visa-auto-auth`).
2. قم برفع هذا المجلد إلى المستودع عبر الأوامر التالية:
   ```bash
   cd android-client-app
   git init
   git add .
   git commit -m "Initial commit for Visa Auto-Auth"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/visa-auto-auth.git
   git push -u origin main
   ```
3. بمجرد الرفع، سيبدأ GitHub Actions تلقائياً في بناء التطبيق:
   * ادخل على تبويب **Actions** في صفحة المستودع على GitHub.
   * انتظر دقيقة واحدة حتى تظهر علامة الصح الخضراء ✅.
   * اضغط على الـ Run وستجد ملف الـ APK جاهزاً للتنزيل المباشر باسم: **VisaAutoAuth-APK**.

---

## 📱 طريقة تشغيل التطبيق على هاتف العميل:

1. أرسل ملف `VisaAutoAuth-v1.0.apk` للعميل ليثبته على هاتفه.
2. يفتح العميل التطبيق ويقوم بالآتي:
   * يكتب بريده الإلكتروني المسجل في السفارة.
   * يضغط على الزر الكبير: **"⚠️ اضغط هنا لتفعيل إذن النقر التلقائي"** لتفعيل خيار إمكانية الوصول في الهاتف.
   * يضغط **"💾 حفظ وبدء الاتصال"**.
3. تظهر له علامة: **🟢 متصل بالسيرفر**.
4. سيعمل التطبيق في الخلفية بهدوء وبأعلى سرعة ممكنة، وبمجرد طلب كود MFA سيقوم بفتح تطبيق المافيفا والتأكيد في ثانية واحدة!
